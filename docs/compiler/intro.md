# 编译器学习笔记

这里记录我学习编译器原理与实现的过程，从词法分析到代码生成。

## 学习路线

1. **前端**：词法分析（Lexer）、语法分析（Parser）、AST
2. **中端**：语义分析、类型检查、IR 生成、优化 Pass
3. **后端**：指令选择、寄存器分配、代码生成
4. **实践**：手写一个小型编译器、学习 LLVM / MLIR

## 关键概念

- SSA（静态单赋值）
- 控制流图 / 数据流分析
- 即时编译（JIT）
- AOT 编译

:::info 说明
编译器笔记注重动手实现，每个阶段都配合可运行的代码。
:::
