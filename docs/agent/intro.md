# Agent 学习笔记

这里记录我学习 AI Agent 相关技术的过程，包括 Agent 架构、工具调用、多 Agent 协作、RAG 等。

## 学习方向

- **Agent 框架**：LangChain、AutoGen、CrewAI
- **工具调用**：Function Calling、Tool Use、MCP
- **多 Agent 协作**：角色分工、通信协议、任务编排
- **RAG**：检索增强生成、向量数据库、Chunk 策略
- **推理优化**：Chain of Thought、Tree of Thoughts、ReAct

每篇笔记都附带代码示例和实践总结。
