分享一下我在学习新技术时总结的方法论，希望对你有帮助。

<!-- truncate -->

## 1. 官方文档优先

遇到新技术，第一时间看官方文档，而不是搜博客。官方文档是最权威、最及时的信息源。博客可以作为补充，但不能替代文档。

## 2. 动手实践

光看不练假把式。每学一个知识点，都要写代码验证。哪怕只是一个最小的示例，也比看十遍文档记得牢。

```javascript
// 示例：学 Promise 时写的最小示例
const promise = new Promise((resolve) => {
  setTimeout(() => resolve('Hello'), 1000);
});
promise.then(console.log);
```

## 3. 费曼学习法

学完一个知识点，尝试用自己的话讲出来（或写出来）。如果讲不清楚，说明还没真正理解。这个博客就是我的费曼学习法实践。

## 4. 建立知识体系

零散的知识点容易遗忘，要把它们组织成体系。我用 Docusaurus 的文档功能按方向分类，就是为了建立知识网络。

## 5. 定期回顾

每周花时间回顾本周学过的内容，每月做一次总结。回顾不是重复阅读，而是尝试默写和应用。

---

学习是一场马拉松，不是短跑。保持节奏，持续积累，时间会给你答案。
