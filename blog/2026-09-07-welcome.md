欢迎来到我的个人技术博客！这里记录我学习技术的点点滴滴。

## 为什么建这个站

学习技术的过程中，我积累了大量的笔记和心得。散落在各个地方的笔记很难检索，也不方便回顾。于是我决定用 Docusaurus 搭建这个站点，把学习过程系统化地记录下来。

## 站点结构

- **文档区**：按技术方向分类的系统性笔记（前端、后端、工具）
- **博客区**：时间线式的学习心得、项目记录、踩坑日记
- **双语支持**：中文为主，部分内容提供英文版

## 技术栈

- **框架**：Docusaurus 3.x
- **部署**：GitHub Pages + GitHub Actions
- **评论**：Giscus（基于 GitHub Discussions）
- **搜索**：本地离线搜索

## 接下来

我会持续更新学习笔记，如果你也在学习技术，欢迎一起交流！
