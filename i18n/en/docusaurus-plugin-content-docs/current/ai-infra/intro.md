# AI Infra Learning Notes

This is where I document my journey learning AI infrastructure, including inference optimization, distributed training, GPU programming, and more.

## Learning Directions

- **Inference Optimization**: vLLM, TensorRT-LLM, KV Cache, PagedAttention, Speculative Decoding
- **Distributed Training**: Data Parallelism, Tensor Parallelism, Pipeline Parallelism, ZeRO
- **GPU Programming**: CUDA, Triton, kernel optimization
- **Model Serving**: Ray Serve, KServe, load balancing, auto-scaling
- **Storage & Networking**: RDMA, NVLink, object storage, checkpoint management

:::tip[Sharpen the axe before chopping the tree]

AI Infra is the core competency in the era of large models. These notes focus on both theory and practice.

:::
