# Compiler Learning Notes

This is where I document my journey learning compiler theory and implementation, from lexing all the way to code generation.

## Learning Roadmap

1. **Frontend**: Lexer, Parser, AST
2. **Mid-end**: Semantic analysis, type checking, IR generation, optimization passes
3. **Backend**: Instruction selection, register allocation, code generation
4. **Practice**: Hand-writing a small compiler, studying LLVM / MLIR

## Key Concepts

- SSA (Static Single Assignment)
- Control Flow Graph / Data Flow Analysis
- Just-In-Time Compilation (JIT)
- Ahead-Of-Time Compilation (AOT)

:::info[Note]

Compiler notes focus on hands-on implementation — every stage comes with runnable code.

:::
