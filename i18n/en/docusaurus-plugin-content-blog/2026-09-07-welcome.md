Welcome to my personal tech blog! This is where I document every step of my tech learning journey.

## Why I Built This Site

Over the course of learning technology, I've accumulated a vast amount of notes and insights scattered across various places — hard to search, inconvenient to review. So I decided to build this site with Docusaurus to systematically record my learning process.

## Site Structure

- **Docs**: Systematic notes organized by technology direction (Agent, Compiler, AI Infra)
- **Blog**: Timeline-style learning reflections, project logs, and troubleshooting diaries
- **Bilingual**: Chinese as the primary language, with English versions for selected content

## Tech Stack

- **Framework**: Docusaurus 3.x
- **Deployment**: GitHub Pages + GitHub Actions
- **Comments**: Giscus (based on GitHub Discussions)
- **Search**: Local offline search

## What's Next

I'll keep updating my learning notes. If you're also learning technology, feel free to reach out and exchange ideas!
